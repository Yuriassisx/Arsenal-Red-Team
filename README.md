# Arsenal Red Team

Ferramentas ofensivas para pentest e bug bounty **autorizados**.

| Ferramenta | Descrição |
|---|---|
| [**ParamHunter**](ParamHunter/) | Scanner de parâmetros vulneráveis + fuzzer de payloads (LFI, SQLi, CMDi, SSRF, XSS, SSTI, XXE, IDOR, JWT, race condition e mais). 12 módulos, 58 encoders de bypass, evasão adaptativa de WAF. |
| [**Misconfig**](Misconfig/) | Scanner single-file de misconfigurations, exposição de dados sensíveis, falhas de API (OWASP API Top 10), SSRF validado out-of-band, fingerprint de tecnologias/CVEs e recon de subdomínios. |

> ⚠️ **Uso legal apenas.** Use somente contra alvos que você está autorizado a
> testar: pentest com contrato assinado, programa de bug bounty dentro do
> escopo, laboratórios/CTF ou ativos próprios.

Veja o README de cada ferramenta na sua respectiva pasta para instalação e uso
detalhado.
